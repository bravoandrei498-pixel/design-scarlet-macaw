Brand Style Guide

The living system for this site: one brand, two accent colors (evergreen + muted gold), two typefaces (Newsreader + Source Sans 3), built on an 8pt grid. Every component used on the site maps to a variant documented here — and renders from the shared tokens.css, never copied values.

01

Brand & Voice

RefinedCalmTrustedUnderstatedPrecise

Voice — Do

  • Speak plainly and warmly
  • Lead with the patient's outcome
  • Be specific ("same-week consults")
  • Sound like a trusted expert, not a salesperson

Voice — Don't

  • Hype, superlatives, or pressure
  • Jargon or clinical coldness
  • Vague claims ("the best care")
  • Emojis or exclamation marks

Button hover: translateY −2px + brighten, 200ms ease-out · Card hover: scale/lift, 200ms · Section entry: fade + 20px rise, 300ms · Dropdown: opacity 0→1 + −4px, 200ms. One timing vocabulary site-wide (Rule 12).

11

Iconography

One family, 1.5px stroke, themed color (never default black/grey). Source: a single MIT-licensed monoline set per project (Lucide, Heroicons, Phosphor, or Tabler — Rule 11). No icons beside eyebrow text (Rule 13).

16

Agent Prompt Guide

Added v12 (Rule 7 §16). This section turns the guide into ammunition for revision sessions — copy a prompt, swap the specifics, paste it to Claude Design. Rule: name the color, never describe it.

Quick color reference — say these names

  • Evergreen 500 #3C5A45 — primary CTA fill
  • Evergreen 700 #2A4233 — button hover, focus ring, icon emphasis
  • Evergreen 900 #16291F — dark anchor (nav / footer / CTA bands)
  • Muted Gold 500 #C2A36B — secondary accent, numerals, dividers
  • Neutral 50 #F5F1E8 — page canvas  ·  Neutral 900 #242621 — ink

Example revision prompts (values inlined — adapt per project)

  1. Button: "Change the hero's primary button to Evergreen 700 #2A4233 with the pill radius; keep the −2px hover lift and 200ms ease-out."
  2. Card: "Give the services cards a Neutral 100 #EEE9DC background, 12px radius, shadow-md — desktop and mobile."
  3. Section background: "Set the testimonials section to Evergreen 50 #ECF2EE with the grain texture at 4% opacity."
  4. Headline: "Make the About H2 duotone: first clause in ink, second clause italic in Muted Gold 700 #9C8049."
  5. Motion: "Swap the stat band's count-up for the odometer variant, same 4 stats, Calm timing."

Iteration rules

  • One component per request — batches per Rule 22c's reconciliation.
  • Reference the variant name from this guide ("the ghost button", "card hover state").
  • State the viewport: desktop, mobile, or both.
  • Voice vocabulary — use: [from Brief — e.g. care, results, straightforward] · avoid: [e.g. cutting-edge, world-class, journey].
