# Section Layout Library
### The creative ceiling — a menu of section *compositions* to build from. Load every build.

*Why this exists: the Core (rules + enforcement) raises the floor but doesn't invent layouts. The "amazing" sites get their range from **section-composition variety** — the same content arranged in bolder, more varied shapes. This is that shelf. Reach into it for every section so the build stops defaulting to safe, identical blocks.*

## How to use it (read before composing)
- **It's a menu, NOT a checklist.** Pick the layout that fits each section's *job*, plus **ONE signature flex** for the whole site. Don't use every pattern — that reads busy, the opposite of premium.
- **Vary composition across the 3 Canvas directions.** Per the (now relaxed) Canvas rule, the three directions should explore genuinely *different section layouts*, not just different skins. Direction A might use two-part splits; B a bento mosaic; C a sticky-scroll narrative.
- **Match motion to the layout** (motions are spec'd in the Core's Motion Menu) and **intensity to the Character dial** (Calm / Balanced / Expressive).
- **Don't stack two "loud" sections back to back.** Alternate a bold composition with a quiet one — rhythm is what keeps a rich page calm.
- **(v12) Declare the spine before building.** Pick the full section list for the page (by each section's job), state it in one sentence, THEN write copy and build — a stated spine is cheap to redirect; a built page isn't.

**(v12) Rhythm rules — the when-NOT-to-use layer** *(Aug 31 2026 — the menu above says
what each pattern is; these say when reaching for one is the wrong move):*
- **Stat bands: three stats max** — four reads as a brochure. **No real number for a
  slot? That's the signal to use a different layout, not to pad** (Rule 3's `00+`
  placeholders are for missing *real* stats, not for inventing a fourth slot).
- **Never two stat rows on one page** — the second one is visual fatigue, not more proof.
- **One pull-quote / statement band per page.** Two in a row reads as filler.
- **No two identical card grids adjacent** — if value props are a 3-card cluster, the
  services section next door must take a different shape (bento, numbered index, tabs).
- **List rows take borders on top, never boxes around** — full boxes turn a clean index
  into a brochure.
- **Horizontal scroll gallery and pinned mask-reveal: once per site, ever** — these are
  signature-tier moves; a second appearance demotes the first.
- **Accordion is for content the visitor chooses to read** (FAQ, what's-included) —
  never for content they must see (pricing terms, primary services).
- **Segmentation chooser only when the audiences genuinely differ** in path or content —
  a chooser over identical destinations is decoration.

## Family 1 — Heroes
- **Layered editorial hero** *(the locked default)* — main image + ONE companion (text-box OR motif image) + optional muted backing square + frame (shape follows image). Proof-cluster for trust verticals. *Default for most.*
- **Full-bleed image/video hero** — edge-to-edge photo or muted looping video (with pause control), headline + CTA over a legibility scrim. *Real estate, hospitality, recovery (calm video).*
- **Split hero** — copy one side, single strong image the other; cleanest, most flexible. *Legal, B2B, healthcare.*
- **Centered editorial hero** — oversized stacked headline, small proof row beneath, image below the fold. Type *is* the hero. *Brand-forward, wellness.*
- **Collage / cluster hero** — 2–3 offset photos + floating chips/stats. Energetic. *Wellness, lifestyle (Expressive).*

## Family 2 — "Important subject" / feature sections *(your "large two-part section")*
- **Large two-part split** — one big section divided into two strong halves (statement + supporting visual, or problem + solution). Bigger and more deliberate than a normal alternating row. *Avyora-style.*
- **Sticky-pinned split** — one half pins while the other scrolls through points; the pinned side can swap image per point. High-craft. *SaaS, premium services.*
- **Offset / asymmetric band** — deliberately uneven columns (e.g. 60/40, image bleeding off one edge) — breaks the boring 50/50. *Editorial, design-led.*
- **Full-width statement band** — a dark/accent band carrying one big idea + a single CTA, image optional. Punctuation between lighter sections.
- **Alternating rows — elevated** — the classic image-left/right, but rescued from boring with offset frames, number anchors, or a per-row accent. Use sparingly; prefer the bolder options above.

## Family 3 — Content representation *(your "creative way to show small content" + "motif heading + small cards")*
- **Bento / mosaic grid** — mixed-size tiles (one big + several small), each a self-contained idea. The modern "feature grid." *Mentaa-style.*
- **Motif-heading + small-card cluster** — an oversized motif/word/numeral as the section anchor, with small content cards arranged around/beside it. *Mindoor-style; great for value props.*
- **Numbered list / index** — big numerals (01–04) anchoring short content rows. Editorial, calm, scannable.
- **Tabbed panel** — one frame, tabs swap the content (services, modalities, audiences). Compact for lots of content.
- **Accordion-reveal** — stacked rows expand in place. FAQ, detailed services, "what's included."
- **Icon/stat row** — a tight horizontal strip of 3–4 mini-stats or checks (not a fat block — single line).
- **Checklist feature** — a claim + a verified checklist beside a supporting image. Trust-building.

## Family 4 — Galleries & imagery *(your "scroll gallery")*
- **Horizontal scroll gallery** — vertical scroll drives a sideways image track. Striking; use once. *Portfolios, real estate, renovation.*
- **Masonry grid** — varied-height image tiles with hover photo-reveal/zoom. *Work, results, team.*
- **Marquee strip** — infinite logo/word/image conveyor. Trust words, partners, certifications.
- **Before/after slider** — draggable reveal. *Renovation, restoration, results.*
- **Pinned mask-reveal** — fixed image stack unmasks as text scrolls (cinematic). *Luxury (Expressive).*

## Family 5 — Proof & trust
- **Stat band (count-up / odometer)** — 3–4 big real numbers that roll up on view. Universal.
- **Testimonial wall** — a grid/masonry of quote cards (static, scannable) — or a **slider** for fewer, longer quotes.
- **Avatar-cluster + rating** — overlapping headshots + "+N" + star rating. Turns proof into an invitation.
- **Logo marquee** — partner/insurance/press logos, looping.
- **Citation cards** — stat + source (e.g. WHO 2023) — rare, high-credibility for health/legal.

## Family 6 — Process / how-it-works
- **3-step "how it works"** — Assessment → Sessions → Tracking; lowers commitment anxiety. Near-required for services.
- **Lighting-up timeline** — steps activate as they scroll into view (horizontal or vertical).
- **Vertical stepper** — numbered stages down the page with connective line; good for detailed processes.

## Family 7 — Conversion / CTA / contact
- **Gradient-mesh CTA band** — animated mesh background, one big headline + primary CTA (+ optional paired secondary).
- **Segmentation chooser** — Individual / Couples / Teen (or tabbed paths) so visitors self-select. Strong conversion UX.
- **Contact split + map** — form one side, map/details + per-location info the other. (Production form is often app-embedded — leave room.)
- **Sticky conversion bar** — appears after the hero scrolls away; never competes with the hero CTA.
- **Alt-channel row** — WhatsApp/live chat + click-to-call, for warm-but-not-ready visitors.

## Family 8 — Team / about
- **Photo-forward card grid** — 3–4 members with hover photo-reveal + a button to the full Team page (don't list everyone).
- **Founder/feature bio** — one credentialed person, portrait + story + credentials. Authority.
- **Art-directed about band** — image one side (consistent treatment), story + signature the other; better than a plain text block.

## Composing combinations (this is where "hundreds" comes from)
A homepage is ~8–12 sections. Pick a layout per section *by its job*, alternate loud/quiet for rhythm, and commit to **one signature** across the whole page. Example spines:

- **Recovery (Calm):** layered hero + proof-cluster → single-line trust strip → motif-heading value cards → two-part "our approach" split → 3-step process → stat band (count-up) → testimonial wall → FAQ accordion → empathy CTA band → mega-footer. *Signature: organic blob + per-section accent.*
- **Real-estate sales (Expressive):** full-bleed video hero → logo marquee → bento listings grid → horizontal scroll gallery → sticky-pinned "why us" split → stat band (odometer) → testimonial slider → contact split + map. *Signature: the scroll gallery.*
- **Legal (Balanced→Calm):** split hero + proof-cluster → citation stat band → numbered practice-area index → founder/feature bio → testimonial wall → FAQ → CTA band. *Signature: the citation cards.*

**(v12) Default rhythm per page type** *(the loud/quiet alternation, made explicit — a
starting shape to deviate from deliberately, not a template):*

| Page | Rhythm (L=loud composition, Q=quiet) | Note |
|---|---|---|
| Home | L (hero) → Q (trust strip) → L (value/feature) → Q (story/split) → L (services) → Q (process) → L (stat band) → Q (testimonials) → Q (FAQ) → L (CTA band) | Never two L back to back; the signature lives in ONE of the L slots |
| Services index | L (hero) → L (services grid) → Q (team strip) → Q (FAQ) → L (CTA) | The grid is the page — everything else stays quiet |
| Service child | Q (hero) → Q (content + sidebar) → Q (process) → Q (proof) → L (CTA) | Child pages are workhorses; one loud moment only, at the close |
| About | L (hero) → Q (story) → L (team or values) → Q (credentials) → L (CTA) | Pick team OR values as the loud one, not both |
| Contact | Q (minimal hero) → L (form split + map) → Q (FAQ) | The form IS the loud section |

Same content, different shelves → different sites. **The Core keeps it correct; this Library keeps it interesting.**
